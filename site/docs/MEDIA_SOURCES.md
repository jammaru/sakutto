## Extension build

From the shallow clone:

```sh
pnpm install --frozen-lockfile
node scripts/sync-licenses.mjs && node scripts/sync-pdfjs.mjs
node scripts/sync-export-font.mjs && node scripts/sync-ocr-runtime.mjs
SAKUTTO_FAKE_ENGINE=1 pnpm exec wxt build
```

The documented e2e stub engine (`SAKUTTO_FAKE_ENGINE=1`) renders the real MV3 content script,
popup, options, PDF reader, image panel and caption overlay without downloading the 573 MB model.
A local-only patch in the gitignored clone suppresses the stub's `§ja§` debug marker and maps
the original fixture sentences to original Japanese copy, so the captures show only product UI.
No secrets, tokens, or private model files are involved.

## Feature story animations (2026-11-26; re-rendered 2026-11-27)

The PDF story uses a small indigo-plant illustration beside the translated pages. The
caption and compose scenes illustrate Sakutto’s documented caption translation and
compose preview and replacement. The captions scene uses the site's indigo photograph; the
interface, caption cues and pointer movement are staged rather than live footage.

The original GIFs baked a light-blue or grey-green matte into every frame, which produced a
second frame inside the indigo tiles. They were replaced on **2026-11-27 (UTC)** with
transparent animated WebP captures rendered in headless Chromium (Playwright) from a staged
720 x 720 HTML/CSS scene, then encoded with `ffmpeg` (`libwebp_anim`, 10-12 fps, eight-second
loop). Because the backgrounds are transparent, the site's own indigo weave tile is the only
surface in both light and dark themes. The old `story-captions.gif` and `story-write.gif`
were removed.

`story-captions.webp` shows three bilingual subtitle cues over the indigo film still, a
subtitle drag, and a running timeline. `story-write.webp` types the Japanese draft, opens the
「あA」translation preview, then replaces the draft with the English translation. Matching
512 px and 720 px WebP posters (`*-poster-512.webp`, `*-poster-720.webp`) are
representative still frames selected by `srcset`/`sizes`; they are served to
`prefers-reduced-motion: reduce` too, and are transparent with the staged
product UI intact.
No new third-party or copyrighted material was introduced.

The strength-card visuals are live, localized HTML/CSS staged in the three
cards; no strength-card images are generated or shipped.
