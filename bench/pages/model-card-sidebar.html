riverlight / plamo-diffusion-1b

A masked diffusion language model fine-tuned for short document translation. Trained on paired paragraphs in eleven languages, released for research use.

  • diffusion
  • translation
  • multilingual
  • masked-lm
  • research

Overview

This model converts an autoregressive checkpoint into a masked diffusion decoder. Full attention layers drop the causal mask, and the sampling loop unmasks the most confident positions first, so a paragraph is produced in a fixed number of passes rather than one token at a time.

The practical effect for translation is that latency depends on the number of refinement steps rather than on the length of the output. Short segments finish in eight passes, while longer paragraphs benefit from sixteen, and the quality difference between the two settings is smaller than the timing difference.

Training data

The fine-tuning set contains roughly nine million paragraph pairs filtered for document alignment, sentence segmentation quality, and language identification confidence. Pairs that failed an automated back-translation check were removed before training, which cut the dataset by about eleven percent and improved the held-out score.

  • News and magazine prose, licensed for research use only.
  • Technical documentation released under permissive licenses.
  • Public-domain fiction and out-of-copyright reference works.

Usage

Load the quantized weights with any runtime that supports the reference chat template and pass the language pair as a structured prefix. The example below runs on CPU with four threads and no GPU offload. 

const runtime = await loadModel("plamo-diffusion-1b-q4.gguf", {
  nCtx: 2048,
  nThreads: 4,
  nGpuLayers: 0,
});
const out = await runtime.translate({ text, src: "en", tgt: "ja" });

Limitations

The model inherits the biases of its training pairs and performs poorly on text that mixes scripts inside a single sentence. Inline markup is preserved only when the request uses the placeholder convention described in the reference implementation, and long inputs should be split at sentence boundaries before they reach the model.

Evaluation was limited to paragraph-level translation with a reference translation available for scoring. Interactive settings, where a user waits for the first characters of a paragraph, were not measured and may behave differently from the reported numbers.
