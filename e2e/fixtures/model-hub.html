diffusion-example-27b

An experimental masked diffusion checkpoint converted from an autoregressive model. Not benchmarked, and not intended for production use.

How it works

example/model-27b is converted into a masked diffusion language model. It generates by iterative parallel unmasking rather than left to right.

  • Full-attention layers: the causal mask is removed, so attention runs in both directions.
  • Gated layers: a forward and reverse scan, with a per-channel gate rev_gate initialised to zero.
  • Mask token: a learned embedding replaces the padding token.
  • Loss: masked-token cross-entropy with a shifted prediction so the language head stays aligned.

Usage

Load the weights with load_pretrained(path), then call the decoder. The fast path is on by default (example/accel.py) and nothing in the API changes.

Set EXAMPLE_FAST=0 to disable the fast path, or EXAMPLE_GRAPH=0 to keep the kernels without the graph capture.

Limitations

Evaluation covered paragraph-level translation with a reference available for scoring. Interactive use, where a reader waits for the first characters, was not measured.
