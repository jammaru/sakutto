# Security policy

## Reporting a vulnerability

Report security issues privately through GitHub's Security tab:

https://github.com/jammaru/sakutto/security/advisories/new

Do not open a public issue, and do not paste private page content, credentials, or personal data.

There is no public email address for this project. GitHub's private vulnerability reporting is the channel.

The maintainer will acknowledge the report and discuss next steps in that private thread.

## Supported versions

Please report against the latest Chrome Web Store release, or against current `main` if the issue is in this repository.

# セキュリティポリシー

## 脆弱性の報告

セキュリティの問題は、GitHub の Security タブから非公開で報告してください。

https://github.com/jammaru/sakutto/security/advisories/new

公開の Issue には書かないでください。非公開ページの本文、認証情報、個人情報も貼らないでください。

このプロジェクトに公開のメールアドレスはありません。GitHub の非公開の脆弱性報告が窓口です。

メンテナはその非公開のスレッドで受け取り、次の手順を案内します。

## 対象バージョン

Chrome ウェブストアの最新版、またはこのリポジトリの現在の `main` を対象にしてください。
